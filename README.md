# Immortel_RPG

Mini RPG narratif développé en Python, inspiré de l'univers de mon roman *Immortel* en cours d'écriture.

## Objectif du projet

Ce projet me sert à apprendre les bases de la programmation avec Python en construisant progressivement un jeu complet.

L'histoire reprend les personnages et l'univers d'*Immortel*, tout en adaptant certains événements pour les besoins du gameplay et de l'apprentissage.

## Fonctionnalités actuelles

- Exploration avec choix du joueur
- Affichage des statistiques du personnage
- Système de combat au tour par tour
- Attaques et compétences physiques
- Gestion des PV et de l'endurance
- Compétences avec coût en ressources
- Système de défense et de réduction des dégâts
- Gestion de la victoire et de la défaite

## Technologies utilisées

- Python
- Git
- GitHub
- Visual Studio Code
